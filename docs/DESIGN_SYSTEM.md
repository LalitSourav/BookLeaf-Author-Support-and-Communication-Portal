# Design System — BookLeaf Portal

## 1. Brand Identity & Tone
- **Publishing Platform Vibe:** Professional, trustworthy, literary, and author-centric.
- **Color Palette:**
  - **Primary:** Deep Slate / Indigo (`#1e293b` / `#3b82f6`)
  - **Accent / Publishing Warmth:** Amber / Gold (`#f59e0b` / `#d97706`)
  - **Neutral Background:** Clean Off-White (`#f8fafc`)
  - **Card / Surface:** Pure White (`#ffffff`) with subtle shadows.
  - **Status Colors:**
    - Success / Live / Resolved: Emerald (`#10b981`)
    - Warning / In Progress: Amber (`#f59e0b`)
    - Critical / Urgent: Rose (`#f43f5e`)

## 2. Typography
- **Font Family:** Inter / system-ui sans-serif.
- **Scale:**
  - Page Headings: text-2xl font-bold tracking-tight text-slate-900
  - Section Headings: text-lg font-semibold text-slate-800
  - Body Text: text-sm text-slate-600
  - Metadata / Badges: text-xs font-medium uppercase tracking-wide

## 3. Component Guidelines
- **Cards:** White background, rounded-xl border border-slate-200 shadow-sm p-6.
- **Tables:** Clean alternating row borders, sticky headers for admin ticket queues.
- **Badges:** Pill-shaped badges with soft background tints for status, category, and priority.
- **Forms:** Floating or clear labeled inputs, focus ring in primary blue, inline validation errors.
